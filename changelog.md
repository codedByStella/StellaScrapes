# StellaScrapes — Changelog

This changelog summarizes public-release maintenance at a feature level. It intentionally omits private source mappings, production query examples, operational measurements, and proprietary selection or scoring details.

## Public release maintenance

- Generalized record normalization across supported input schemas.
- Improved handling of city and state display values.
- Corrected record-type handling in the public processing interface.
- Improved test invocation and reporting.
- Clarified availability reporting for unsupported retrieval adapters.
- Tightened fuzzy matching to reduce accidental matches.
- Removed duplicate placeholder entries from the public registry.
- Added a browser interface alongside the Python command-line workflow.
- Kept production retrieval and proprietary processing components outside this public release.

## Ongoing work

- Maintain consistent behavior across Python and Node.js interfaces.
- Improve validation, error handling, and export safety.
- Expand automated tests for normalization and supported public interfaces.
- Document source-specific usage requirements and responsible request rates.
